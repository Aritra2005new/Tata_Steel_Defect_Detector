🔍 Project: Tata Steel Defect Analyzer

The application is designed to identify and classify steel surface defects using Deep Learning and Computer Vision techniques, providing an intelligent inspection workflow for industrial-quality analysis.

🚀 Key Features:
• Automated steel defect classification using MobileNetV2
• Detection of multiple defect categories:

- Crazing
- Inclusion
- Patches
- Pitted
- Rolled-in Scale
- Scratches
  • Invalid image detection for non-steel inputs
  • Fully integrated full-stack deployment with live inference

🛠 Technologies Used:
React.js • Flask REST API • PyTorch • CNN ( MobileNetV2 )
• Computer Vision  • Vercel
 • Hugging Face
